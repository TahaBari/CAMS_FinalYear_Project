# College Admission Management System (CAMS)
## 📋 Project Overview
The College Admission Management System (CAMS) is a web-based platform designed to simplify and streamline the college admission process. This project enables students to apply for courses online, track their application status, and provides administrators with tools to manage student data effectively.
## 🛠️ Features
### For Students:
- User-friendly registration and login interface.
- Online application submission for multiple programs.
- Ability to upload required documents securely.
- Real-time application status tracking.
### For Administrators:
- Admin dashboard for managing student applications.
- Document verification and approval/rejection of applications.
- Generating merit lists based on predefined criteria.
- Efficient student data management.
💻 Technologies Used
- Backend: PHP
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Version Control: Git
